# National Automotive Technical Institute Excellence Training Website

This is a responsive South African-focused website starter for National Automotive Technical Institute Excellence Training.

## Files
- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — mobile menu, year and enquiry interaction

## Publish with GitHub Pages
1. Create/open your GitHub repository.
2. Upload `index.html`, `style.css` and `script.js` to the repository root.
3. Commit the files.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select your main branch and `/ (root)`, then save.
7. GitHub will provide the public website address.

## Before publishing
Replace:
- +27 00 000 0000
- info@natiexcellence.co.za
- the placeholder South African address
- course names/details with the institute's official information
- gallery placeholders with real photographs
- any accreditation/registration wording only with information that can be verified

The enquiry form is currently a front-end demonstration. Connect it to the institute's real email/WhatsApp/form service before using it for applications.
